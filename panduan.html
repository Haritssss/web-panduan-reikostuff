Langkah 01

Buka Folder Utama Steam

Pertama, close aplikasi Steam kamu sampai benar-benar mati. Terus ke desktop PC, klik kanan icon Steam, dan pilih opsi Open file location buat langsung masuk ke foldernya.

🗔 Open
🛡️ Run as administrator
📁 Open file location Klik
⭐ Add to Favorites
Tips: Pastikan cek system tray (pojok kanan bawah taskbar) juga ya, pastiin Steam-nya udah beneran exit biar file-nya nggak bentrok.
Langkah 02

Copy-Paste File (.dll)

Ambil 2 file .dll yang tadi udah kamu download sebelumnya. Langsung paste ke dalam folder Steam yang tadi kebuka. Kalau muncul notifikasi dari Windows, langsung klik Overwrite / Replace aja.

📂 Root Folder: Steam /
📁bin
📁config
⚙️unlocker.dll
⚙️dwmapi.dll
⚙️steam.exe
Langkah 03

Bikin Folder "lua"

Masih di dalam folder Steam tadi, cari dan masuk ke folder yang namanya config. Di dalam folder config itu, bikin folder baru dan kasih nama lua. Ingat ya, wajib huruf kecil semua!

📂 Folder Directory: Steam / config /
📁avatarcache
📁lua
📄config.vdf
Langkah 04

Masukin File Script Lua

Sekarang masuk ke folder lua yang baru aja kamu bikin. Pindahin file script Lua kamu (contohnya file 2483190.lua) ke dalam folder ini. Kalau udah, tinggal buka lagi deh aplikasi Steam kamu. Selesai!

📂 Folder Directory: Steam / config / lua /
📄2483190.lua
